## 🚀 دی‌ان‌اس فایتر چیست؟

**دی‌ان‌اس فایتر** یک ابزار خط فرمان قدرتمند و **چند ریسمانی** برای ویندوز است که به طور خودکار نام دامنه‌ها را با استفاده از چندین سرور DNS حل می‌کند و آی‌پی‌های به‌دست‌آمده را مستقیم در فایل **hosts** ویندوز ذخیره می‌کند.  
با این کار، رزولور (حل‌کننده) پیش‌فرض سیستم به کلی دور زده می‌شود؛ یعنی دیگر خبری از **حملات مسمومیت DNS** نیست، مرور وب سریع‌تر می‌شود و شما کنترل کاملی روی آی‌پی‌هایی که کامپیوترتان به آن‌ها وصل می‌شود دارید.

> 💡 **این یعنی چه برای شما؟**  
> - **جلوگیری از هدایت شما به وب‌سایت‌های جعلی توسط هکرها (اسپوفینگ DNS)**  
> - **افزایش سرعت بارگذاری صفحه** با حذف مرحلهٔ جستجوی DNS  
> - **مقایسهٔ نتایج** تا ۴ سرور DNS مختلف به طور همزمان  
> - **تست پروتکل‌های پیشرفته** (ICMP، TCP/80، TCP/443، UDP/53، HTTP GET، HTTPS GET و دست دادن TLS) برای بررسی در دسترس بودن  
> - **به‌روزرسانی خودکار فایل hosts** با آی‌پی‌هایی که خودتان انتخاب می‌کنید

## 🚀 دی‌ان‌اس فایتر چه کارهایی می‌تواند بکند؟

| ویژگی | توضیح |
|-------|-------|
| 🛡️ **جلوگیری از مسمومیت DNS** | ذخیرهٔ آی‌پی‌های حل‌شده در فایل `hosts` ویندوز و دور زدن رزولور سیستمی |
| ⚡ **سرعت بسیار بالا** | حل همزمان با چند ریسمان (`MAX_WORKERS = 40`) – حتی برای صدها دامنه |
| 🔍 **مقایسهٔ چند DNS** | انتخاب تا ۴ سرور DNS (گوگل، کلودفلر، شکن، بگزار و ...) و مقایسهٔ پاسخ‌ها در یک جدول خوانا |
| 📈 **تست دسترسی پیشرفته** | تست **۷ پروتکل مختلف** روی آی‌پی‌های به‌دست‌آمده از هر رزولور و نمایش نتیجه با ✓ / ✗ |
| 🔄 **به‌روزرسانی خودکار** | بعد از انتخاب یک رزولور، دی‌ان‌اس فایتر انتخاب شما را ذخیره کرده و هر چند ساعت یک‌بار فایل hosts را بدون سؤال مجدد به‌روز می‌کند |
| 📁 **دسته‌بندی دامنه‌ها** | سازماندهی دامنه‌ها در فایل `domains.txt` با دسته‌بندی (فونت‌ها، CDNها، ردیاب‌ها و ...). دامنه‌های جدید در دستهٔ «کاربری» قرار می‌گیرند |
| 🎮 **حالت تعاملی و غیرتعاملی** | استفادهٔ دستی یا ادغام در اسکریپت‌ها و برنامه‌ریز وظایف ویندوز با آرگومان‌های خط فرمان |
| 💰 **رایگان و متن‌باز** | منتشر شده زیر **مجوز MIT** – بدون قید و شرط، اما حمایت شما باعث ادامهٔ توسعه می‌شود |

## 🛠️ نصب

### مرحلهٔ ۱: نصب پایتون (در صورت نصب نبودن)

1. آخرین نسخهٔ پایتون را از [python.org](https://www.python.org/downloads/) دانلود کنید.  
2. نصب‌کننده را اجرا کنید – **خیلی مهم**: گزینهٔ ✅ **"Add Python to PATH"** را در پایین پنجره تیک بزنید.  
3. روی **Install Now** کلیک کنید و صبر کنید تا نصب تمام شود.  
4. برای اطمینان از نصب صحیح، خط فرمان (CMD) را باز کنید و بنویسید:
   ```cmd
   python --version
   ```
   باید چیزی شبیه `Python 3.12.x` ببینید.

> 📖 **آموزش تصویری؟**  
> این ویدیوی ۲ دقیقه‌ای را ببینید: [آموزش نصب پایتون و افزودن به PATH](https://www.youtube.com/watch?v=Kn1HF3o0G_U) (یوتیوب).

### مرحلهٔ ۲: نصب کتابخانهٔ مورد نیاز (`dnspython`)

#### 🚀 **روش خودکار (توصیه شده)**

روی فایل **`install_dependencies.bat`** که داخل پوشهٔ پروژه است دوبار کلیک کنید.  
این فایل به طور خودکار کتابخانه را با استفاده از یک آینهٔ سریع ایرانی نصب می‌کند (و در صورت نیاز به PyPI اصلی برمی‌گردد).  
یک پنجرهٔ خط فرمان باز می‌شود، نصب انجام می‌شود و بعد از آن از شما می‌خواهد یک کلید بزنید – پس از آن آمادهٔ استفاده از دی‌ان‌اس فایتر هستید.

#### 🔧 **روش دستی (اگر روش خودکار کار نکرد یا فیلتر شد)**

خط فرمان را **به عنوان ادمین** باز کنید و یکی از دستورهای زیر را اجرا کنید:

- **استفاده از آینهٔ ایرانی (توصیه شده برای داخل ایران):**
  ```cmd
  pip install dnspython -i https://mirror-pypi.runflare.com/simple/ --trusted-host mirror-pypi.runflare.com
  ```

- **نصب مستقیم (اگر آینه مسدود است):**
  ```cmd
  pip install dnspython
  ```

- **اگر پشت پروکسی هستید:**
  ```cmd
  pip install dnspython --proxy http://your-proxy-address:port
  ```

> ✅ کتابخانه بسیار کوچک است (کمتر از ۲۰۰ کیلوبایت) و در چند ثانیه نصب می‌شود.

## 🎮 نحوهٔ استفاده

### ۱️⃣ حالت تعاملی (پیش‌فرض)

برنامه را با دسترسی ادمین اجرا کنید – می‌توانید روی `admin_run.bat` دوبار کلیک کنید یا خط فرمان را به عنوان ادمین باز کنید و بنویسید:

```cmd
python dns_fighter.py
```

سپس مراحل راهنما را دنبال کنید:

- انتخاب منبع دامنه (استفاده از دسته‌بندی موجود یا وارد کردن دستی دامنه‌های جدید).
- انتخاب حداکثر ۴ رزولور DNS.
- تنظیم زمان انتظار (۱‑۵ ثانیه، پیش‌فرض ۲).
- فعال/غیرفعال کردن بررسی پینگ و به‌روزرسانی خودکار.

بعد از نمایش جدول مقایسه، می‌توانید:

- یک **عدد** وارد کنید تا نتایج همان رزولور برای **همهٔ** دامنه‌ها اعمال شود.  
- **`p`** را وارد کنید تا برای هر دامنه به صورت جداگانه تصمیم بگیرید.  
- **`c`** را وارد کنید تا از **اجماع** (آی‌پی که بیشترین تکرار را در بین همهٔ رزولورها دارد) استفاده کنید.  
- **`a`** را وارد کنید تا **تست دسترسی پیشرفته** (بررسی پروتکل‌ها) روی یک رزولور خاص اجرا شود.

### ۲️⃣ تست دسترسی پیشرفته

بعد از انتخاب `a` و انتخاب یک رزولور، دی‌ان‌اس فایتر:

- هر آی‌پی را با ۷ پروتکل تست می‌کند.  
- جدول جداگانه‌ای با علامت ✓ / ✗ نشان می‌دهد.  
- از شما می‌پرسد کدام پروتکل‌ها باید موفق باشند.  
- **فقط دامنه‌هایی که همهٔ پروتکل‌های انتخاب شده را پاس کنند** نگه می‌دارد و سپس آن‌ها را ذخیره می‌کند.

### ۳️⃣ حالت به‌روزرسانی خودکار

وقتی حالت خودکار را فعال می‌کنید، اسکریپت:

- یک بار به صورت تعاملی اجرا می‌شود تا به شما اجازه دهد یک رزولور (یا اجماع) انتخاب کنید.  
- انتخاب شما را در فایل `last_resolver.txt` ذخیره می‌کند.  
- سپس **وارد یک حلقهٔ بی‌پایان می‌شود** و فایل hosts را هر X ساعت **بدون پرسیدن هیچ سوال دیگری** به‌روز می‌کند – دقیقاً همان انتخاب قبلی شما را تکرار می‌کند.

### ۴️⃣ حالت غیرتعاملی (برای خودکارسازی)

```cmd
python dns_fighter.py --non-interactive --domains-file domains.txt --dns-list 1,4 --ping --timeout 3
```

| آرگومان | توضیح |
|----------|-------------|
| `--auto-update` | اجرای مداوم. |
| `--interval` | فاصلهٔ زمانی بر حسب ثانیه (برای حالت خودکار). |
| `--domains-file` | فایل متنی ساده شامل دامنه‌ها (هر خط یک دامنه، بدون دسته‌بندی). |
| `--dns-list` | کلیدهای DNS با کاما (مثلاً `1,3,5` یا `local`). |
| `--non-interactive` | بدون سؤال از کاربر – تأیید خودکار. |
| `--use-resolver` | اعمال نتایج رزولور شمارهٔ N (شماره از ۱ شروع می‌شود) برای همهٔ دامنه‌ها. |
| `--ping` | فعال کردن بررسی پینگ. |
| `--timeout` | زمان انتظار برای هر درخواست DNS (۱‑۵ ثانیه، پیش‌فرض ۲). |
