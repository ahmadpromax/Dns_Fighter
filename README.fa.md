## 🚀 دی‌ان‌اس فایتر چیست؟

**دی‌ان‌اس فایتر** یک ابزار خط فرمان سریع و چندریسمانی برای ویندوز است که به طور خودکار نام دامنه‌ها را با استفاده از چندین سرور DNS حل می‌کند و آی‌پی‌های به‌دست‌آمده را مستقیماً در فایل **hosts** ویندوز ذخیره می‌کند. با این کار، رزولور (حل‌کننده) پیش‌فرض سیستم به کلی دور زده می‌شود.

**مزایا:**

- 🛡️ **مسدودسازی مسمومیت DNS** – دیگر خبری از وب‌سایت‌های جعلی نیست
- ⚡ **مرور سریع‌تر** – حذف تأخیر جستجوی DNS (۰ میلی‌ثانیه!)
- 🔍 **مقایسه تا ۴ سرور DNS** به صورت همزمان
- 📈 **تست پروتکل‌های پیشرفته** – ICMP، TCP، UDP، HTTP، HTTPS، TLS
- 🔄 **به‌روزرسانی خودکار** – تنظیم کنید و فراموشش کنید

## 📂 چرا این دامنه‌ها؟

فایل `domains.txt` شامل **بیش از ۳۰۰ دامنه انتخابی** برای افزایش سرعت و حریم خصوصی است.

| دسته | مزیت |
|------|-------|
| **فونت‌ها** | بارگذاری سریع فونت در هر وب‌سایتی |
| **CDNهای عمومی** | کش کتابخانه‌های رایج JS/CSS (مثل jQuery، Bootstrap) |
| **ردیاب‌ها و آنالیتیکس** | کاهش ردیابی، بهبود حریم خصوصی |
| **شبکه‌های تبلیغاتی** | مسدودسازی تأخیر تبلیغات |
| **پخش ویدیو** | کاهش بافرینگ (یوتیوب، نتفلیکس و ...) |
| **سرویس‌های کپچا** | تأیید سریع‌تر کپچا |
| **به‌روزرسانی مایکروسافت** | به‌روزرسانی سریع‌تر ویندوز / آفیس |
| **منابع وردپرس** | دانلود سریع‌تر افزونه / قالب |
| **CDNها و ابزارهای ایرانی** | دسترسی بسیار سریع‌تر برای کاربران داخل ایران |
| **دامنه‌های سفارشی کاربر** | اضافه کردن دامنه‌های خودتان |

> 💡 **نحوه استفاده:** دی‌ان‌اس فایتر را اجرا کنید، گزینه **«استفاده از دسته‌بندی موجود»** را انتخاب کنید، و ابزار همه این دامنه‌ها را برای شما حل و ذخیره می‌کند. می‌توانید هر زمان `domains.txt` را ویرایش کنید – اسکریپت ساختار را حفظ می‌کند.

## 🎮 نحوه استفاده

### ۱️⃣ حالت تعاملی (پیش‌فرض)

به عنوان ادمین اجرا کنید – روی `admin_run.bat` دوبار کلیک کنید یا CMD را به عنوان ادمین باز کرده و بنویسید:

```cmd
python dns_fighter.py
```

سپس مراحل راهنما را دنبال کنید:

- انتخاب منبع دامنه (دسته‌بندی موجود یا ورود دستی)
- انتخاب حداکثر ۴ رزولور DNS
- تنظیم زمان انتظار (۱‑۵ ثانیه، پیش‌فرض ۲)
- فعال/غیرفعال کردن بررسی پینگ و به‌روزرسانی خودکار

بعد از نمایش جدول مقایسه:

- یک **عدد** وارد کنید تا از نتایج همان رزولور برای **همه** دامنه‌ها استفاده شود
- **`p`** را وارد کنید تا برای هر دامنه به صورت جداگانه انتخاب کنید
- **`c`** را وارد کنید تا از **اجماع** (آی‌پی پرتکرار) استفاده کنید
- **`a`** را وارد کنید تا **تست دسترسی پیشرفته** را اجرا کنید

### ۲️⃣ تست دسترسی پیشرفته

`a` را انتخاب کنید، یک رزولور را انتخاب کنید، و دی‌ان‌اس فایتر:

- هر آی‌پی را با ۷ پروتکل تست می‌کند
- جدولی با علامت ✓ / ✗ نشان می‌دهد
- می‌پرسد کدام پروتکل‌ها باید موفق باشند
- **فقط دامنه‌هایی که همه پروتکل‌های انتخاب شده را پاس کنند** نگه می‌دارد – سپس آن‌ها را ذخیره می‌کند

### ۳️⃣ حالت به‌روزرسانی خودکار

وقتی حالت خودکار را فعال می‌کنید:

- یک بار به صورت تعاملی اجرا می‌شود تا به شما اجازه دهد یک رزولور (یا اجماع) انتخاب کنید
- انتخاب شما را در `last_resolver.txt` ذخیره می‌کند
- سپس فایل hosts را هر X ساعت **بدون سؤال مجدد** به‌روز می‌کند

### ۴️⃣ حالت غیرتعاملی (برای خودکارسازی)

```cmd
python dns_fighter.py --non-interactive --domains-file domains.txt --dns-list 1,4 --ping --timeout 3
```

**آرگومان‌ها:**

| آرگومان | توضیح |
|----------|-------------|
| `--auto-update` | اجرای مداوم |
| `--interval` | فاصله زمانی بر حسب ثانیه (برای به‌روزرسانی خودکار) |
| `--domains-file` | فایل متنی ساده با دامنه‌ها (یک دامنه در هر خط) |
| `--dns-list` | کلیدهای DNS با کاما (مثلاً `1,3,5` یا `local`) |
| `--non-interactive` | بدون درخواست از کاربر – تأیید خودکار |
| `--use-resolver` | اعمال نتایج رزولور شماره N (شماره ۱-پایه) برای همه دامنه‌ها |
| `--ping` | فعال کردن بررسی پینگ |
| `--timeout` | زمان انتظار برای درخواست DNS (۱‑۵ ثانیه، پیش‌فرض ۲) |
